- **JavaScript** – Interactive functionality

- Personal introduction and About Me section

- Education information

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/himabindu0322/himabindu-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd himabindu-portfolio
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.
